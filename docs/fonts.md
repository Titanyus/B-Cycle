# Ziffernschrift

Die App enthält die unveränderte Schrift **Bebas Neue Regular, Version 2.000 (2018)**
von **Dharma Type / Ryoichi Tsunekawa**. Lizenz: **SIL Open Font License 1.1**.

Quelle: [dharmatype/Bebas-Neue](https://github.com/dharmatype/Bebas-Neue/tree/46e72cec95ee599f72c0de4a12cfe64828949236),
Datei `fonts/BebasNeue(2018)ByDhamraType/ttf/BebasNeue-Regular.ttf`.
Die 61.400 Byte große Schrift liegt unter `app/src/main/res/font/bebas_neue.ttf`.
Der vollständige mitgelieferte Lizenztext liegt unter
[Bebas-Neue-OFL.txt](../app/src/main/assets/Bebas-Neue-OFL.txt) und ist in der App
über **MENÜ → Schrift & Lizenz** lesbar. Die Schrift ist Bestandteil der App,
kein separat verkauftes Produkt. Beschriftungen verwenden Androids Systemschrift.
