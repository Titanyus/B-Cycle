# B|CYCLE 0.8.58

Änderungen seit Build98:

- Statistik: Y-Skalen links oberhalb der durchgehenden horizontalen Rasterlinien, gemeinsam für Monat und Woche.
- HRV: weiße Korridorfüllung von30% auf15% Deckkraft reduziert; gepunktete Grenzen unverändert.
- HRV: getrennte Y-Skalen je Kennzahl und Tag/Woche/Monat, jeweils aus kompletter zugehöriger Serie einschließlich Verlaufskurve/Korridor. Beim Pan/Zoom fest; bisherige Randreserve erhalten.
- Dashboard-Statuszeile: beidseitig mindestens15dp Randabstand; zusätzlich gemeldeten Android-Datenschutzindikatorbereich automatisch aussparen. Keine pauschalen25dp rechts, keine zusätzlichen Berechtigungen.

Prüfstand: sechs gezielte Statistikfälle, neun HRV-Achsen-/Scrollfälle sowie13Status-/Vollbildfälle erfolgreich. Native Vorschauen aktualisiert; Typografie/Atlas/Diff geprüft. Keine Gesamtsuite und kein neuer Telefon-/privater Cloudtest. Android meldet reservierte Indikatorflächen, keinen zuverlässigen Sichtbarkeitsstatus; Poco F7 Ultra muss praktisch geprüft werden.
