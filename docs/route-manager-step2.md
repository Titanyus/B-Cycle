# Streckenmanager – Schritt 2

Die Liste enthält keine Drei-Punkte-, Cloud- oder Speicheraktionen mehr. Das Auge sitzt rechts in der Titelzeile und blendet wie bisher den Track auf der Dashboard-Karte ein oder aus. Die übrige Zeile öffnet die Details mit ihren fünf festen Footer-Aktionen. Beim Einblenden einer anderen Strecke wird diese mit der bisherigen zentralen Funktion ausgewählt. Das aktive Auge bzw. `eye-closed` zeigt den aktuellen Sichtbarkeitsstatus. Der Manager bleibt offen; ein Augen-Klick öffnet weder Details noch ein eigenes Kartenfenster.

Unter Datum/Uhrzeit stehen Distanz, Bewegungszeit und Bewegungsdurchschnitt nebeneinander. Der Durchschnitt kommt ausschließlich aus `RouteDetails.movingAverageKmh`: Distanz / Bewegungszeit, niemals Distanz / verstrichene Zeit. Fehlende, negative, nicht endliche Werte, eine Bewegungszeit von null und widersprüchliche Zeitangaben liefern keinen Durchschnitt. Unbekannte Einzelwerte bleiben leer. Vorhandene zentrale Import-/Aufzeichnungsberechnungen liefern weiterhin die Datenbasis; keine Änderungen an FIT-Rohdaten oder Sensorverarbeitung.

Messwerte verwenden Bebas Neue; kleine Einheiten werden durch dieselbe `AnalysisValueRow` wie in den Details vertikal zentriert und verwenden `BicycleDesign.dashboardUnitColor`. Labels bleiben im Systemfont. Geometrie und Schriftgrößen sind zentrale Designkonstanten. Titel und Datum bleiben einzeilig; Titel werden gekürzt. Native ListView-Recycling, Filter, Sortierung, Import und feine Trenner bleiben erhalten. Herkunft/Dateiformat und ein nicht anklickbarer Hinweis auf den lokalen Originaldateistatus bleiben sichtbar. Cloud- und externe Speichernachweise bleiben im Datenmodell und im Detail-Footer erhalten.

Tests prüfen getrennte Dashboard-Sichtbarkeits-/Details-Klicks, Rückkehr zum unveränderten gefilterten Manager, gesperrte Aktionen während Dateiverarbeitung, fehlende Originaldateien, unveränderte Theme-Geometrie, schmale und breite Ansichten, zentrierte graue Einheiten, leere Listen und korrekte Bewegungsdurchschnitte einschließlich fehlender/widersprüchlicher Daten und Persistenz. Die bisherigen Verwaltungsaktionen werden weiterhin über den Detail-Footer geprüft.

Vollständige Testsuite nach der korrigierten Dashboard-Augenfunktion: 267 Tests, 0 Fehler, 0 Fehlschläge, 0 übersprungen; Release-Build und Release-Lint-Vital erfolgreich. APK-Version 0.7.5/43. Nur die bekannte Produktionswarnung `onBackPressed()` bleibt. Gerätetest steht aus.
