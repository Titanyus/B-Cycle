# Schriften für die HTML-Vorschau

Diese Dateien gehören ausschließlich zur Dokumentation und werden nicht in die APK eingebunden. Der Generator bettet sie in die alleinstehende HTML-Datei ein.

- BebasNeue-Regular.ttf: unveränderte bisherige App-Schrift, nur zum historischen Vergleich; SIL OFL in Bebas-Neue-OFL.txt.
- RobotoCondensed-latin.woff: Latin-Teilmenge der Google-Fonts-Schrift aus `google/fonts/ofl/robotocondensed`, als WOFF für den optionalen Schriftvergleich; SIL OFL in RobotoCondensed-OFL.txt. Keine App-Abhängigkeit.
- Aktuelle League Gothic: direkt aus app/src/main/res/font/league_gothic.ttf; Lizenz aus app/src/main/assets/League-Gothic-OFL.txt. Herkunft und SHA-256 in docs/fonts.md.
